# DiscussionBridge

DiscussionBridge connects websites to hosted discussion communities, starting
with Astro, Starlight, and Discourse.

The project focuses on practical publishing workflows:

- create or connect Discourse topics from site content
- embed discussions cleanly in Astro and Starlight sites
- support static-site and Cloudflare deployment workflows
- document real-world setup patterns as they are proven

## Current Repositories

- [`discussionbridge.dev`](https://github.com/DiscussionBridge/discussionbridge.dev)
  - product site, ecosystem notes, demos, and support structure
- [`astro-discussion-bridge`](https://github.com/DiscussionBridge/astro-discussion-bridge)
  - Astro integration toolkit for Discourse-backed discussions
